# tutaluy-site

קוד האתר החי של tutaluy.com — אתר תדמית של תותלוי בע"מ (TUTALUY LTD).

- `index.html` + `support.js` — האתר הראשי (שש לשוניות)
- `assets/` — תמונות וסקריפטים
- `calc/` — מחשבון בופר סידן לשקי קוקוס (tutaluy.com/calc)
- `robots.txt` — גרסה מתוקנת שמתירה אינדוקס

פריסה: השרת (nitur-caddy) מושך מהריפו הזה אוטומטית (cron כל 5 דקות).
ייבוא ראשוני: ‎.github/workflows/import-site.yml מושך את הקבצים מהאתר החי.
